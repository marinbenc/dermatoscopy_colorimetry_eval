## File structure overview

- `data/` contains the synthetic dataset and supporiting files used in the paper
- `data/output_10k` the downloaded S-SYNTH dataset (explained below)
- `data/<test/train/valid>_files.csv` the files used in the training, validation and testing of the model. Generated during training (explained below.)
- `notebook.ipynb` the main notebook that contains the analysis of colorimetry results.
- `get_ita_for_data.py` a script that generates the ITA values for the synthetic dataset using three ITA estimation methods.
- `ita_values.csv` the ITA values generated by the script above.
- `mel_range.csv` the empirical threshold values used to obtain GT Fitzpatrick skin types from the melanosome fraction value of each image, generated by the script `get_mel_range.py`. (See below)
- `get_mel_range.py` a script that generates the empirical threshold values used to obtain GT Fitzpatrick skin types from the melanosome fraction value of each image. (See below)
- `<train/test>_fp_regression.py` the scripts used to train the FP ordinal regression neural network.
- `fp_regression_test_results.csv` the results of the FP ordinal regression neural network on the test set. Generated by the script `test_fp_regression.py`.
- `test_fp_regression.py` a script that runs predictions on the test set using the FP ordinal regression neural network.

Other files were used during paper development but their results are not reported in the paper. They are included for completeness.

## Reproducing the paper results

### 1) Downloading the data

The S-SYNTH dataset can be downloaded here: https://huggingface.co/datasets/didsr/ssynth_data

To reproduce the results, the [output_10k.zip](https://huggingface.co/datasets/didsr/ssynth_data/blob/main/data/synthetic_dataset/output_10k.zip) file must be uncompressed in the `data/` directory. Example: `data/output_10k/output/skin_000/hairModel_000/mel_0.3/fB_0.002/lesion_13/T_050/HbO2x1.0Epix0.25/hairAlb_0.57-0.57-0.57/light_comfy_cafe_4k/ROT0-0-1_315/` would contain the image and segmentation mask for that parameter combination.

### 2) Generating the ITA values

The script `get_ita_for_data.py` generates the ITA values for the synthetic dataset using three ITA estimation methods. The script uses the `data/output_10k` directory as input and generates the `ita_values.csv` file.

### 3) Generating the "ground-truth" Fitzpatrick labels

The script `get_mel_range.py` generates the empirical threshold values used to obtain GT Fitzpatrick skin types from the melanosome fraction value of each image. The script uses the `data/output_10k` directory as input as well as the `ita_values.csv` file and generates the `mel_range.csv` file.

### 4) Training the FP ordinal regression neural network

The scripts `train_fp_regression.py` are used to train the FP ordinal regression neural network. The training script uses the `data/output_10k` directory as input as well as the `mel_range.csv` file. The training script generates the `<test/train/valid>_files.csv` files.

### 5) Running predictions on the test set

The script `test_fp_regression.py` is used to run predictions on the test set. The script uses the `data/output_10k` directory as input as well as the  `mel_range.csv` file. The script generates the `fp_regression_test_results.csv` file.

### 6) Running the notebook

The `notebook.ipynb` notebook contains the analysis of colorimetry results. The notebook uses the `data/output_10k` directory as input as well as the `ita_values.csv` and `fp_regression_test_results.csv` files.

## Using the colorimetry methods on your own images

The colorimetry methods used in the paper are available in the `get_ita_for_data.py` script. You can take a look at the script for an example on how to use the methods on your own images.

The ITA estimation methods are as follows: 

- **Segmentation-based / "SSYNTH" method.** This method uses the segmentation masks provided in the S-SYNTH dataset to calculate the ITA values. It is equivalent to the ITA calculation method in the SSYNTH paper and code.
- **Color quantization / "kmeans" method.** This method uses the k-means clustering algorithm to calculate the ITA values. It is equivalent to the ITA calculation method in Benčević et al., Understanding skin color bias in deep learning-based skin lesion segmentation, https://doi.org/10.1016/j.cmpb.2024.108044, code: https://github.com/marinbenc/lesion_segmentation_bias
- **Patch-based / "Bevan" method.** This method samples patches of the image and determines ITA based on the lightest patch. It is based on Bevan and Atapour-Abarghouei, Detecting Melanoma Fairly: Skin Tone Detection and Debiasing for Skin Lesion Classification, https://arxiv.org/abs/2202.02832, and the code is from the Kalb et al., Revisiting Skin Tone Fairness in Dermatological Lesion Classification, https://github.com/tkalbl/RevisitingSkinToneFairness
